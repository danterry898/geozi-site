Geozi

A small geometry application inspired by GeoGebra, written in Rust using the native Windows API. Built from scratch, one feature at a time.

Features

Geozi combines basic geometric constructions with mathematical tools in a native desktop application.

Geometry tools

Points, lines, segments, circles and polygons, with tools for parallel and perpendicular lines.

Function plotting

Plot mathematical functions and explore them alongside geometric constructions.

Measurements

Work with angles, distances and polygon areas.

Editing

Move points, undo actions, and edit constructions without having to start over.

Save and load

Save constructions to .gsp files and load them again later.

Custom interface

An adaptive grid, zoom controls and customizable interface themes.

Technical details

One of the main goals of Geozi is to build a desktop application without relying on a GUI framework.

  • Language Rust
  • Platform Windows
  • Windowing and input Direct Win32 API calls
  • Rendering Custom pixel-buffer rendering
  • Dependencies No external crates or GUI framework
  • Scene format .gsp
Geozi is an ongoing personal project. The source code is available on GitHub.
