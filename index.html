Geometry,

Geozi is a small GeoGebra-inspired geometry app built from scratch in Rust. Points, lines, functions, polygons — all inside a native Windows application.

What you can do

More than just
drawing lines.

A collection of geometry tools and small quality-of-life features, built one piece at a time.

⌖

Points & constructions

Create points, segments and infinite lines. Move existing points and construct parallel or perpendicular lines.

◯

Circles & polygons

Draw circles, free polygons and regular polygons to build more complex constructions.

ƒ

Function plotting

Plot f(x) and explore mathematical curves alongside your geometric constructions.

∠

Angles & measurements

Measure angles, calculate distances and find polygon areas using the shoelace formula.

↶

Undo & editing

Undo changes, select and delete objects, and use the pen and eraser tools.

⊞

Grid & customization

An adaptive grid, zoom controls, custom themes and save/load support for your constructions.

Under the hood

Built, not assembled.

The implementation is part of the project. No engine or GUI framework doing the heavy lifting.

A native approach

Geozi uses Rust with direct Win32 API calls to create and manage its Windows interface. The rendering is handled through a manually managed pixel buffer rather than an external graphics or UI framework.

Save your constructions

Geozi has its own .gsp scene format, so constructions can be saved and loaded. Editing tools and undo support make it easier to experiment without starting over.
